# HyggeTerminal
Denne terminal er bare min hygge playground til at lære den.

Dette er redigeret gennem nano --->

pt. har vi Forretningsdesign & Analytics, men jeg øver mig lige på dette, da det er pisse hyggeligt!

Funktioner:

cat - kig ind i filens indhold.

nano - rediger en fil.

cd - flyt ind i en fil (ændring af placering i filsti).

pwd - hvor er jeg nu?

grep - søger efter tekstmønstre, hvis man fx skal søge i indholdet uden af rykke sig i filstien.

cli/ - terminal vinduets kommando.

core/ - agent logik, fx vibe. 

touch - create ny fil.
